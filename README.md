# FILM!

Приложение для просмотра фильмов и бронирования билетов.

## Демо

Проект развернут на удаленном сервере и доступен по ссылке: 
**[http://85.143.174.203](http://85.143.174.203)**

## Стек технологий
* **Frontend:** React, Vite
* **Backend:** NestJS, TypeORM
* **База данных:** PostgreSQL
* **Инфраструктура:** Docker, Docker Compose, Nginx, GitHub Actions (GHCR)

## Запуск проекта локально (через Docker)

Самый простой способ запустить проект — использовать Docker Compose. Убедитесь, что у вас установлен и запущен Docker.

1. Скопируйте пример файла окружения:
   `cp .env.example .env`

2. Соберите и запустите контейнеры:
   `docker compose up -d --build`

3. Приложение будет доступно по адресу: `http://localhost` (порт 80).
4. pgAdmin (веб-интерфейс для БД) будет доступен по адресу: `http://localhost:8080`.

## Запуск для разработки (без Docker)

### Бэкенд
Перейдите в папку с бэкендом:
`cd backend`

Установите зависимости:
`npm ci`

Создайте файл `.env` на основе `.env.example` и укажите параметры подключения к вашей локальной базе PostgreSQL (переменные `DATABASE_HOST`, `DATABASE_PORT`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`, `DATABASE_NAME`).

Запустите сервер в режиме разработки:
`npm run start:dev`

### Фронтенд
Перейдите в папку с фронтендом:
`cd frontend`

Установите зависимости и запустите dev-сервер:
`npm ci`
`npm run dev`

## Тестирование

В папке `backend` настроены unit-тесты (Jest). Для запуска выполните:
`cd backend`
`npm test`

## Логирование

В проекте реализовано три вида логгеров: `DevLogger`, `JsonLogger` и `TskvLogger`. Выбор логгера осуществляется через переменную окружения `LOG_FORMAT` в файле `.env` (доступные значения: `dev`, `json`, `tskv`).
